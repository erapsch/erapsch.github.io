## Contributing

This repository is my personal academic website, not a general-purpose project, so it isn't
open to outside contributions. Issues and pull requests here will generally be closed.

If you'd like to contribute to the **template** this site is built on — bug fixes, features,
or styling questions — please head to the upstream **Academic Pages** project instead:

- Repository: <https://github.com/academicpages/academicpages.github.io>
- Report a bug or request a feature: <https://github.com/academicpages/academicpages.github.io/issues/new/choose>
- Ask a styling question: <https://github.com/academicpages/academicpages.github.io/discussions>

Thanks for understanding, and be excellent to each other.
